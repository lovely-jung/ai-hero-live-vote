실시간 갤러리

아직 제출된 그림이 없어요. 그림이 들어오면 여기에 바로 나타나요.

참가자

● 접속 중 · ✅ 완성 · 💬 마지막 한마디 · 이름을 누르면 내보내기
📄 결과 CSV 저장

심사 기준: 창의성 · 주제 표현력 · 완성도 · 재미 (각 10점, 총 40점). 그려진 사람의 외모는 평가하지 않고, 그림의 표현과 아이디어만 평가합니다. 진행자가 직접 입력한 점수가 AI 점수보다 우선합니다. 동점이면 창의성 → 좋아요 → 먼저 제출한 순입니다.

현재 순위

    점수가 입력되면 순위가 나타나요.

    시상식 진행

    1. 프로젝터에 📺 프로젝터 화면을 띄워 두세요 (위 오른쪽 버튼).
    2. 시상식 시작을 누르면 큰 화면이 시상 화면으로 바뀝니다.
    3. 다음 ▶을 누를 때마다 3위 → 2위 → 1위 → 전체 순위 순서로 공개됩니다.
    4. 큰 화면 아래쪽 조작 바(마우스를 움직이면 나타남)나 키보드 → ← 로도 넘길 수 있어요.

    공개될 순위 미리보기

    시연용 데이터

    예시 참가자 10명과 캐릭터 8개(한마디·하트·점수·작품 별명 포함)를 넣습니다. 큰 화면에서 바로 🏆 순위 발표까지 시연할 수 있어요.

    초기화

    새 라운드: 그림과 점수만 지우고 접속한 참가자는 그대로 둡니다. 참가자 화면은 새 그림판으로 바뀝니다.

    전체 초기화: 참가자, 그림, 점수를 모두 지웁니다. 참가자는 이름을 다시 입력해야 합니다.

    다른 기기에서 진행하기

    아래 링크를 다른 노트북·태블릿에서 열면 같은 대회를 진행할 수 있어요. 진행자 키가 들어 있으니 학생에게 보여주지 마세요.
